# 小说下载

## 触发条件
- 用户说"下载XX小说"、"帮我下载XX"、"找XX的txt"
- 用户提供小说名 + 明确表示要下载

## 执行步骤
1. 确认用户要下载的小说名（中英文均可，如"斗破苍穹"、"问道红尘"）
2. 调 `download_novel(novel_name=小说名)` 下载文本
3. 下载完成后告知用户文件保存路径和章节数
4. 如果文件较大，可以询问用户是否需要分段阅读

## 输出格式
- 下载中：告知用户"正在下载《XX小说》，请稍候..."
- 完成后：告知"已下载完成！共 XX 章，保存在 `novels/XX.txt`"
- 失败时：说明原因（小说名未找到/网络超时/已存在）

## 注意事项
- 支持调用已配置的小说下载源；找不到结果时如实返回下载源错误
- 下载可能耗时较长，告知用户耐心等待
- 注意版权：仅用于个人阅读学习
