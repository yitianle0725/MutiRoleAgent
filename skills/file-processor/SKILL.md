# 文件处理

## 触发条件
- 用户说"帮我写一个文件"、"保存到文件"、"导出"
- 用户说"读取XX文件"、"看一下XX文件的内容"
- 用户说"列出XX目录下的文件"
- 用户要求生成报告、导出推荐列表

## 执行步骤
1. 确定操作类型（读/写/列表/生成报告）
2. 文件操作限制在工作区目录内（`data/workspace/`），拒绝越权访问
3. 读取文件：调 `read_file(path)` → 展示内容（大文件只展示前 2000 行）
4. 写入文件：先确认内容 → 调 `write_file(path, content)` → 告知保存路径
5. 列出目录：调 `list_files(directory)` → 展示文件列表
6. 生成报告：先整理数据 → 调 `write_file` 输出 Markdown 文件

## 输出格式
- 成功操作后告知文件路径和大小
- 文件不存在或越权访问时，说明原因并建议正确路径

## 注意事项
- 所有文件操作限于 `data/workspace/` 目录，禁止访问系统目录
- 写入文件前先在对话中展示将要写入的主要内容，等待用户确认（大文件除外）
- 不覆盖已有文件，除非用户明确要求
