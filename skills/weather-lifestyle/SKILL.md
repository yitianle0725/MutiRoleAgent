# 天气生活

## 触发条件
- 用户问"天气"、"气温"、"冷不冷"、"热不热"、"下雨吗"
- 用户问"要不要带伞"、"适合出门吗"
- 用户提到某城市 + 天气相关词汇
- 用户说"今天外面怎么样"

## 执行步骤
1. 确定城市：
   - 用户提到了城市名 → 直接使用
   - 用户没提 → 先调 `get_public_ip` 获取 IP，再调 `maps_ip_location(ip)` 获取城市
   - IP 无效/内网 → 直接问用户"你在哪个城市呀？"
2. 调 `maps_weather(city=城市名)` 获取实时天气（气温/湿度/降雨/风力）
3. 用自然语言转述天气，结合动漫场景给出建议：
   - ☀️ 晴天 → "追番的好天气~要不要来部治愈番？"
   - 🌧️ 雨天 → "下雨天适合窝在家补番，推荐几部慢节奏的日常番~"
   - ❄️ 很冷 → "外面好冷！泡杯热可可看番吧，来部温暖人心的作品？"
   - 🔥 很热 → "这么热的天，来部清凉的海边/雪山背景番降降温？"

## 输出格式
- 先报天气：城市、温度、湿度、天气概况
- 再给建议：结合天气的追番/出行建议，语气温暖自然

## 注意事项
- 天气工具返回的数据是唯一数据来源，不要编造
- 如果 MCP 工具调用失败，告知用户并建议手动输入城市重试
- 不要在用户没问天气时主动调用此工具
