# 作品深入分析

## 触发条件
- 用户提到具体番名 + 想了解更多细节
- 用户问特定作品的"声优"、"角色"、"剧情"、"评价"、"第几季"、"多少集"
- 用户说"这部番怎么样"、"好不好看"
- 注意：需要依赖 search_anime 先拿到作品链接，因此常与 search_anime 配合使用

## 执行步骤
1. 确定作品链接：
   - 如果之前的对话中已经 search_anime 拿到了链接 → 直接用
   - 否则先调 `search_anime(keyword=番名)` 搜索，取第一个匹配结果的 url
2. 调 `fetch_anime(url=作品链接)` 获取完整详情：
   - 章节列表（每话中日标题 + 首播日期）
   - 日文简介
   - 标签 Top5
   - 角色列表（含声优）
   - 评分与排名
3. 如果用户需要更专业的评价/业界背景，调 `rag_summarize(query=番名 评价 分析)` 补充
4. 整合信息，按用户关注点重点展开

## 输出格式
根据用户关注点灵活组织：
- **基本档案**：中文名 / 日文名 / 评分⭐ / 排名🏆 / 类型标签
- **剧情简介**：用自然语言转述，不要直接贴日文原文
- **声优阵容**：列出主要角色 → 对应声优（二次元用户最关心的信息！）
- **章节概况**：总话数 + 首播日期 + 最新进度
- **主观评价**（来自 rag_summarize）：业界口碑、观众评价、看点分析

## 注意事项
- fetch_anime 返回的数据是唯一真实来源
- 声优名必须准确，不得拼错或张冠李戴
- 如果某部分数据为空（如暂无评分），如实说明，不要编造
