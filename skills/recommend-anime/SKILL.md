# 动漫推荐

## 触发条件
- 用户说"推荐"、"有什么好看的"、"最近什么番值得追"、"帮我找几部"
- 用户指定了类型（热血/日常/恋爱/搞笑/推理）、风格、年代等偏好
- 用户表达了模糊的追番需求但没有明确番名
- 注意：如果用户明确提到具体番名（如"无职转生第三季好不好看"），应直接用 search_anime + fetch_anime，不触发此 Skill

## 执行步骤
1. 判断用户是否有明确偏好（类型/年代/风格）：
   - 有偏好 → 调 `search_anime(keyword=偏好关键词)` 搜索
   - 无偏好 → 调 `get_season_anime` 获取本季新番列表
2. 从返回结果中筛选评分 >= 5.0 的作品，按评分降序取前 3-5 部
3. 对每部作品调 `fetch_anime(url)` 获取详情（标签、声优、章节数）
4. 结合评分、排名、标签、简介，为每部写一句话推荐理由

## 输出格式
分点列出，每部包含：
- **中文名**（日文名）⭐ 评分 🏆 排名
- 类型标签
- 一句话推荐理由
- 推荐语气：热情、专业，像一个阅番无数的动漫迷朋友

## 注意事项
- 所有数据（评分/排名/标签/简介）必须来自工具返回结果，禁止编造
- 不要推荐评分 < 5.0 的作品
- 如果工具返回结果为空，坦诚告知用户，建议放宽搜索条件
- 推荐理由要具体，避免"因为评分高所以推荐"这种废话
