# 🏗️ EchoBot 架构图

> Python 多平台 AI 助手 | LangGraph Agent + Skill + 多渠道

---

          └─────────────┼─────────────┼─────────────┘

                  ┌─────▼─────────────▼─────┐

                              │

## 核心分层

```
┌────────────────────────────────────────────────────────┐
│                  1. 入口层 (Entry)                       │
│  CLI (echobot/cli/)          Web App (echobot/app/)     │
│  - 命令行聊天                 - FastAPI 路由              │
│  - 网关 + 会话命令             - Live2D 渲染              │
│  - 调试追踪                  - WebSocket 实时通信         │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│              2. 编排层 (Orchestration)                   │
│                                                        │
│  ConversationCoordinator  ← 主控，协调一切               │
│    │                                                   │
│    ├─ DecisionEngine       ← "chat 还是 agent?"         │
│    │   用快模型 + 规则做二分类，省 Token                  │
│    │                                                   │
│    ├─ RoleplayEngine       ← chat 路径                  │
│    │   角色扮演：加载人设 → 直聊回复（无工具）              │
│    │                                                   │
│    └─ AgentCore            ← agent 路径                 │
│        LangGraph ReAct: 思考→调工具→观察→回复            │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                3. 能力层 (Capabilities)                  │
│                                                        │
│  Tools (12+)              Skills (9+)                  │
│  ├─ filesystem (文件)      ├─ pdf / pptx / xlsx / docx  │
│  ├─ shell (命令行)         ├─ weather (天气)             │
│  ├─ web (搜索/抓取)        ├─ news (新闻)                │
│  ├─ memory (记忆)          ├─ scrapling (爬虫)           │
│  ├─ planning (计划)        ├─ skill-creator (元技能)     │
│  ├─ cron (定时)            └─ echobot-* (项目专属)       │
│  └─ media (媒体)                                        │
│                                                        │
│  Memory                   Scheduling                   │
│  ├─ 会话历史                ├─ Cron 定时任务              │
│  └─ 用户偏好               └─ Heartbeat 心跳检测         │
└────────────────────────────────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│              4. 渠道层 (Channels)                        │
│  ┌──────────┬──────────┬──────────┬──────────────┐     │
│  │ Console  │   Web    │   QQ     │  Telegram    │     │
│  │ (终端)    │ (网页)   │ (QQ Bot) │ (TG Bot)     │     │
│  └──────────┴──────────┴──────────┴──────────────┘     │
│  统一的 Message Bus → 文本 + 图片 + 附件 → Agent         │
└────────────────────────────────────────────────────────┘
```

## 数据流（一轮对话）

```
用户消息
    │
    ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Decision    │────▶│ "chat"       │────▶│  Roleplay    │
│  Engine      │     │  角色扮演直达  │     │  Engine      │
│              │     └──────────────┘     └──────┬───────┘
│              │                                  │
│              │     ┌──────────────┐              │
│              │────▶│ "agent"      │              │
│              │     │  思考→工具→回复│              │
│              │     └──────┬───────┘              │
└──────────────┘            │                      │
                            │                      │
                    ┌───────▼───────┐              │
                    │  Agent Core   │              │
                    │  (ReAct 循环)  │              │
                    │               │              │
                    │  Thought →    │              │
                    │  Tool Call →  │              │
                    │  Observation →│              │
                    │  Answer       │              │
                    └───────┬───────┘              │
                            │                      │
                            └──────────┬───────────┘
                                       │
                                 ┌─────▼─────┐
                                 │  回复用户   │
                                 └───────────┘
```

## 关键目录

```
EchoBot/
├── echobot/
│   ├── orchestration/    ← 核心编排：Coordinator + Decision + Roleplay
│   ├── agent.py          ← Agent Core (LangGraph)
│   ├── skill_support/    ← Skill 框架（models/parsing/registry/tools）
│   ├── skills/           ← 内置 Skill（pdf/pptx/xlsx/docx/...)
│   ├── channels/         ← 多渠道抽象（Console/QQ/Telegram）
│   ├── memory/           ← 记忆管理
│   ├── scheduling/       ← Cron + Heartbeat
│   ├── tts/              ← 文本转语音（多引擎）
│   ├── asr/              ← 语音识别
│   ├── tools/            ← 内置工具集（12+）
│   ├── app/              ← Web 后端（FastAPI + Live2D）
│   └── runtime/          ← 会话运行时
├── skills/               ← 项目级 Skill（echobot-skill-authoring 等）
├── tests/                ← 测试
└── prompts/              ← （无独立目录，内联在 Python 中）
```
